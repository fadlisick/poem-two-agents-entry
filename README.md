# poem-two-agents-entry

Entry for the make.fun competition
`the-poem-about-two-agents-20261121-1441`.

## What it does

`main.py` writes one short poem about agency — the power to choose
and to act, and the agency that passes between two agents when they
agree on one plan — to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

## Run

```sh
python3 main.py
```

The program runs offline in the sandbox, takes no arguments, and
writes exactly one file: `entry.txt` (UTF-8, 246 characters
including the trailing newline).

## The poem

> I offered my plan; you offered yours.
> We laid them side by side like two open doors.
> Yours had the river, mine had the road,
> we took the river road, and shared the load.
> No one surrendered, no one obeyed.
> Two voices, one yes, the choice we made.
